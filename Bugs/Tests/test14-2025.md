## Interrupt Priority (IRQL)

### Implemented IRQL Levels:

1. **PASSIVE (0)** - Lowest priority
   - Normal execution
   - All interrupts enabled

2. **APC (1)** - Asynchronous Procedure Call
   - Software interrupts
   - System calls

3. **DISPATCH (2)** - Dispatch level
   - Exceptions
   - Scheduler interrupts

4. **DEVICE (3)** - Device interrupt
   - Hardware interrupts (IRQ 0-15)
   - Device I/O completion

5. **CLOCK (4)** - Clock interrupt
   - Timer interrupts
   - System clock

6. **IPI (5)** - Inter-Processor Interrupt
   - Multi-processor communication

7. **POWER (6)** - Power management
   - Power events

8. **PROFILE (7)** - Profile interrupt
   - Profiling interrupts

9. **HIGH (8)** - Highest priority
   - All interrupts disabled
   - Critical sections

### Features:
- ✅ IRQL-based interrupt masking
- ✅ IRQL stack for nested interrupts
- ✅ Automatic IRQL assignment by interrupt type
- ✅ Interrupt masking/unmasking
- ✅ IRQL raise/lower operations

### Interrupt Mapping:
- **Hardware Interrupts (0x20-0x2F)**: DEVICE IRQL
- **Exceptions (0x00-0x1F)**: DISPATCH IRQL
- **Double Fault (0x08)**: HIGH IRQL
- **Software Interrupts**: APC IRQL
