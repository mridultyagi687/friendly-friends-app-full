## Windows 10/11 Required Features

All critical feature bits that Windows 10/11 checks are now set:

### ✅ Critical Features (Windows BSODs without these)

1. **CMPXCHG16B** (Leaf 1, ECX bit 13)
   - 128-bit atomic compare-and-exchange
   - Windows kernel uses this extensively

2. **SSE2** (Leaf 1, EDX bit 26)
   - Streaming SIMD Extensions 2
   - Windows requires this for basic operations

3. **SYSCALL/SYSRET** (Leaf 0x80000001, EDX bit 11)
   - Fast system call mechanism
   - Windows uses this for system calls

4. **NX Bit** (Leaf 0x80000001, EDX bit 20)
   - No-Execute bit support
   - Required for DEP (Data Execution Prevention)

5. **Long Mode** (Leaf 0x80000001, EDX bit 29)
   - 64-bit mode support
   - Windows 10/11 is 64-bit only

6. **LAHF/SAHF in 64-bit mode** (Leaf 0x80000001, ECX bit 0)
   - Load/Store AH register in 64-bit mode
   - Windows requires this

7. **AVX2** (Leaf 7, EBX bit 5)
   - Advanced Vector Extensions 2
   - Windows 11 checks for this

8. **48-bit Virtual Addresses** (Leaf 0x80000008)
   - Windows requires 48-bit virtual address space

### ✅ Additional Features

- **PAE** (Physical Address Extension) - For memory > 4GB
- **MMX, SSE, SSE3, SSSE3, SSE4.1, SSE4.2** - SIMD instructions
- **AVX, FMA, F16C** - Advanced floating-point
- **POPCNT, LZCNT** - Bit manipulation
- **RDRAND, RDSEED** - Random number generation
- **BMI1, BMI2** - Bit manipulation instructions
- **XSAVE, OSXSAVE** - Extended state management
- **HTT** (Hyper-Threading Technology) - Multi-threading
