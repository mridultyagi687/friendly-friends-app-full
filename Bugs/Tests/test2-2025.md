## Issues Identified

### 1. Instruction Structure Mismatch
- Tests assume separate methods for JZ/JNZ, but implementation uses `executeJCC`
- Tests assume register-to-register operations work the same as memory operations
- Tests don't set `opcode.relative` flag for relative jumps/calls

### 2. Implementation Details
- `AND/OR/XOR` expect `rToM: true` for memory operations, but register-to-register (mod=3) needs different handling
- `SHL/SHR` use `executeSHIFT` which handles multiple shift operations
- `MUL/DIV/IMUL` use `executeMULDIV` which handles multiple arithmetic operations

## Recommendations

2. **Add register-to-register operation support** in AND/OR/XOR if not already present

3. **Document instruction execution methods** to clarify which methods handle which instructions
