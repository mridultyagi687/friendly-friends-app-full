## Implementation Details

### ✅ CPU State Additions

1. **XCR0 Register**
   - Added `cpu.xcr0` as 64-bit BigInt, initialized to 0n
   - Controls which extended states are saved/restored by XSAVE/XRSTOR

2. **Register Storage**
   - XMM registers (xmm0..xmm15) - 128-bit each
   - YMM upper halves (ymm0..ymm15) - upper 128 bits for YMM
   - FP state: `cpu.fcw`, `cpu.fsw`, `cpu.ftw`, `cpu.mxcsr`

### ✅ XGETBV Implementation

- Reads XCR register specified in ECX
- Returns value in EDX:EAX (64-bit)
- Supports XCR0 (index 0)
- Returns 0 for unknown XCR indices

### ✅ XSETBV Implementation

- Writes EDX:EAX to XCR register specified in ECX
- Requires CPL == 0 (privileged instruction)
- Validates reserved bits: only allows bits 0 (x87), 1 (XMM), 2 (YMM) - `allowedMask = 0x7n`
- Raises #GP if reserved bits set or invalid XCR index

### ✅ FXSAVE / FXRSTOR Implementation

- Standard FXSAVE layout (512 bytes):
  - FCW, FSW, FTW (6 bytes)
  - FPU registers (8 x 80-bit = 128 bytes, padded to 16 bytes each)
  - MXCSR, MXCSR_MASK (8 bytes)
  - XMM registers (16 x 128-bit = 256 bytes)
- Correctly saves and restores all FPU/SSE state

### ✅ XSAVE / XRSTOR Implementation

- Standard XSAVE layout:
  - Offset 0-511: FXSAVE area (if XCR0 bit 0 or 1 set)
  - Offset 512-575: XSAVE header (64 bytes, always present)
    - XSTATE_BV (8 bytes) - which components are saved
    - XCOMP_BV (8 bytes) - compressed format (not used)
    - Reserved (48 bytes)
  - Offset 576+: Extended regions
    - YMM upper halves (256 bytes at offset 576, if XCR0 bit 2 set)
- XRSTOR validates xstate_bv: raises #UD if unsupported bits set
- Respects XCR0 when saving/restoring state

### ✅ 64-bit ADD Flag Semantics Fix

- Fixed flag calculation using correct BigInt arithmetic:
  - `MASK64 = (1n << 64n) - 1n`
  - `SIGN64 = 1n << 63n`
  - `sum = (a + b) & MASK64`
  - `CF = (a + b) > MASK64` (using unmasked sum)
  - `OF = (((~(a ^ b)) & (a ^ sum)) & SIGN64) !== 0n`
  - `ZF = (sum === 0n) ? 1 : 0`
  - `SF = ((sum & SIGN64) !== 0n) ? 1 : 0`
  - `AF = (((a ^ b ^ sum) & 0x10n) !== 0n) ? 1 : 0`
- Applied to ADD, SUB, ADC, SBB operations
