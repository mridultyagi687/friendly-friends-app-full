## Failing Test

### ADD Instruction with Flags
**File:** `src/emulator/core/instruction-coverage.test.js`  
**Test:** `should execute ADD with flags`

**Error:**
```
AssertionError: expected 2147483647n to be 2147483648n
- Expected: 0x80000000n
+ Received: 0x7FFFFFFFn
```

**Issue:**
- 32-bit overflow calculation in ADD instruction
- Test expects: 0x7FFFFFFF + 1 = 0x80000000 (signed overflow)
- Actual result: 0x7FFFFFFF (no overflow detected)

**Root Cause:**
- ADD instruction not properly handling 32-bit overflow
- Result masking may be happening before overflow detection
- Flag calculation may be incorrect for 32-bit mode
