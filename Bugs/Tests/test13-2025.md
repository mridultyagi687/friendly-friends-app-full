## UEFI Event Services

### Implemented Services:

#### 1. Create Event
- Creates new event with type, notify TPL, and optional notification function
- Returns event handle
- Supports all UEFI event types

#### 2. Close Event
- Closes an event and signals all waiters
- Cleans up event resources

#### 3. Signal Event
- Signals an event, waking all waiters
- Calls notification function if set
- Resolves all pending wait operations

#### 4. Wait For Event
- Waits for one or more events to be signaled
- Returns index of signaled event
- Supports timeout (1 second default)
- Async/await support

#### 5. Check Event
- Non-blocking check if event is signaled
- Returns EFI_SUCCESS if signaled, EFI_NOT_READY if not

## UEFI Timer Services

### Implemented Services:

#### Set Timer
- **TimerCancel (0)**: Cancels existing timer
- **TimerPeriodic (1)**: Creates periodic timer (repeats)
- **TimerRelative (2)**: Creates one-shot timer (fires once)

**Features:**
- Converts 100ns units to milliseconds
- Automatically cleans up timers
- Signals associated event when timer fires
- Supports multiple concurrent timers

## TPL (Task Priority Level) Management

### Implemented Services:

#### Raise TPL
- Raises current TPL to specified level
- Saves previous TPL on stack
- Returns previous TPL level

#### Restore TPL
- Restores previous TPL from stack
- Maintains TPL stack for nested calls

**TPL Levels:**
- 0: Application TPL (lowest)
- Higher values: Higher priority (interrupts disabled)
