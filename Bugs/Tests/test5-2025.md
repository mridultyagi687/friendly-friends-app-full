- **Status:** Implemented
- **Instructions Updated:**
  - `MOVS` (MOVSB, MOVSW) - REP, REPE, REPNE support
  - `STOS` (STOSB, STOSW) - REP, REPE, REPNE support
  - `CMPS` (CMPSB, CMPSW) - REP, REPE, REPNE support
  - `SCAS` (SCASB, SCASW) - REP, REPE, REPNE support

- **Implementation Details:**
  - REP: Repeat while RCX > 0
  - REPE/REPZ: Repeat while ZF = 1 and RCX > 0
  - REPNE/REPNZ: Repeat while ZF = 0 and RCX > 0
  - Safety limit: 10,000 iterations max per instruction
