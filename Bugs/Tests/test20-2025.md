- **0x060: PPR** - Processor Priority Register (read-only, calculated)
- **0x070: EOI** - End of Interrupt Register (write-only)
- **0x080: RRD** - Remote Read Register (read-only)
- **0x090: LDR** - Logical Destination Register
- **0x0A0: DFR** - Destination Format Register
- **0x0B0: SVR** - Spurious Interrupt Vector Register (CRITICAL)
- **0x0D0-0x0F0: ISR** - In-Service Register (8 x 32-bit)
- **0x0E0-0x100: TMR** - Trigger Mode Register (8 x 32-bit)
- **0x0F0-0x110: IRR** - Interrupt Request Register (8 x 32-bit)
- **0x280: ESR** - Error Status Register
- **0x300: ICR_LOW** - Interrupt Command Register Low
- **0x310: ICR_HIGH** - Interrupt Command Register High
- **0x320: LVT_TIMER** - Local Vector Table Timer
- **0x330: LVT_THERMAL** - Local Vector Table Thermal Sensor

- **0x370: LVT_ERROR** - Local Vector Table Error
- **0x380: INITIAL_COUNT** - Timer Initial Count Register
- **0x390: CURRENT_COUNT** - Timer Current Count Register (read-only)
- **0x3E0: DIVIDE_CONFIG** - Timer Divide Configuration Register

### ✅ APIC Timer

**Features:**
- **Initial Count Register (0x380):** Sets timer countdown value
- **Current Count Register (0x390):** Read-only, shows current countdown
- **Divide Configuration Register (0x3E0):** Sets timer divisor (1, 2, 4, 8, 16, 32, 64, 128)
- **LVT Timer (0x320):** Configures timer interrupt vector and mode
- **Timer Modes:**
  - One-shot mode (delivery mode 0): Timer counts down once
  - Periodic mode (delivery mode 1): Timer auto-reloads
- **Timer Interrupts:** Triggers interrupt when count reaches 0

**Implementation:**
- Timer runs at configurable frequency (default 1 MHz)
- Divisor applied from DIVIDE_CONFIG
- Updates CURRENT_COUNT based on elapsed time
- Triggers interrupt via LVT_TIMER vector when expired

### ✅ TPR (Task Priority Register)

**Features:**
- **Priority Class (bits 4-7):** Task priority class (0-15)
- **Priority Sub-class (bits 0-3):** Task priority sub-class (0-15)
- **Interrupt Blocking:** Interrupts with priority below TPR are blocked
- **APR Calculation:** Arbitration Priority = TPR with sub-class cleared
- **PPR Calculation:** Processor Priority = max(TPR, highest ISR priority)

**Implementation:**
- `getTPR()`: Returns current TPR value
- `setTPR()`: Sets TPR value
- `calculateAPR()`: Calculates Arbitration Priority Register
- `calculatePPR()`: Calculates Processor Priority Register
- Interrupt delivery checks TPR before delivering

### ✅ EOI (End of Interrupt)

**Features:**
- **Write-only Register (0x0B0):** Writing any value acknowledges interrupt
- **ISR Clearing:** Clears highest priority bit in In-Service Register
- **Interrupt Completion:** Marks interrupt as completed
- **Next Interrupt:** Automatically delivers next pending interrupt if available

**Implementation:**
- `handleEOI()`: Clears highest priority ISR bit
- Updates `inServiceVector` to next highest ISR
- Automatically delivers next pending interrupt
- Properly handles interrupt priority ordering

### ✅ Spurious Vector

**Features:**
- **SVR Register (0x0B0):** Bits 0-3 contain spurious vector (default 0xFF)
- **Spurious Interrupts:** Delivered even when APIC is disabled
- **No EOI Required:** Spurious interrupts don't set ISR bits
- **Handling:** Spurious interrupts are logged but don't require acknowledgment

**Implementation:**
- Spurious vector stored in `spuriousVector` (from SVR bits 0-3)
- `handleSpuriousInterrupt()`: Handles spurious interrupt delivery
- Spurious interrupts bypass normal interrupt delivery flow

### ✅ SIPI (Startup Inter-Processor Interrupt)

**Features:**
- **ICR Delivery Mode 6:** Startup IPI (SIPI)
- **Vector as Address:** Vector bits 0-7 specify page-aligned startup address
- **AP Startup:** Used to start application processors
- **Multi-Processor Support:** Ready for multi-CPU emulation

**Implementation:**
- `sendSIPI()`: Sends SIPI to target APIC
- Extracts startup address from vector (bits 0-7 << 12)
- Logs SIPI delivery (in single-processor mode, would start target CPU)
- Ready for multi-processor extension

### ✅ Memory-Mapped I/O Integration

**Features:**
- **APIC Base Address:** 0xFEE00000 (standard LAPIC base)
- **MMIO Range:** 4KB (0xFEE00000 - 0xFEE00FFF)
- **Memory Manager Integration:** APIC registers accessible via memory reads/writes
- **Size Support:** 8-bit, 16-bit, 32-bit, 64-bit accesses

**Implementation:**
- `registerMMIODevice()`: Registers APIC as MMIO device
- `getMMIODevice()`: Checks if address is in MMIO range
- `readByte/Word/Dword/Qword()`: Routes APIC accesses to device
- `writeByte/Word/Dword/Qword()`: Routes APIC writes to device
- Bypasses write protection for MMIO (MMIO is always writable)

### ✅ Interrupt Delivery

**Features:**
- **IRR (Interrupt Request Register):** Tracks pending interrupts
- **ISR (In-Service Register):** Tracks interrupts being serviced
- **TMR (Trigger Mode Register):** Tracks edge/level triggered interrupts
- **Priority Ordering:** Interrupts delivered by priority (highest first)
- **TPR Blocking:** Interrupts below TPR priority are blocked

**Implementation:**
- `deliverInterrupt()`: Adds interrupt to pending queue
- `deliverNextInterrupt()`: Delivers highest priority pending interrupt
- Sets IRR bit when interrupt arrives
- Moves to ISR when interrupt is delivered
- Clears IRR bit when interrupt enters service
- Clears ISR bit when EOI is written
