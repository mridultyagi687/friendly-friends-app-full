# Test Results - XGETBV, XSAVE, XRSTOR Implementation with XMM + YMM Support

**Date:** 2025-01-07  
**Test Run:** test18-2025  
**Status:** ✅ XGETBV, XSAVE, XRSTOR correctly implemented with XMM + YMM state support

## Summary

Implemented correct XGETBV, XSAVE, and XRSTOR instructions with full support for XMM (SSE) and YMM (AVX) state. XCR0 now properly controls which extended states are saved/restored.

## Implementation Details

### ✅ XCR0 Register

1. **Added XCR0 Register to CPU**
   - XCR0 is now a real register in the CPU (not just a function)
   - Default value: `0x07` (bits 0, 1, 2 set)
     - Bit 0: X87 FPU state
     - Bit 1: SSE/XMM registers
     - Bit 2: AVX/YMM registers (upper 128 bits)

2. **XCR0 Functions**
   - `getXCR0()`: Reads from the actual XCR0 register
   - `setXCR0(value)`: Sets XCR0 register (for future XSETBV support)

### ✅ YMM Registers

3. **Added YMM Registers to CPU**
   - 16 x 256-bit YMM registers (ymm0-ymm15)
   - YMM registers extend XMM registers:
     - Lower 128 bits: XMM register (xmm0-xmm15)
     - Upper 128 bits: YMM register (ymm0-ymm15)

### ✅ XGETBV Instruction

4. **XGETBV Implementation**
   - Reads XCR register specified in ECX
   - Returns value in EDX:EAX (64-bit)
   - Currently supports XCR0 (ECX = 0)
   - Returns actual XCR0 register value

### ✅ XSAVE Instruction

5. **XSAVE Implementation**
   - Saves extended state based on XCR0 bits
   - **XSAVE Header (64 bytes):**
     - XSTATE_BV (8 bytes): Which components are saved
     - XCOMP_BV (8 bytes): Compressed format (not used)
     - Reserved (48 bytes)
   
   - **State Areas (based on XCR0):**
     - **X87 (if bit 0 set):** 512 bytes
       - FPU control/status/tag words
       - 8 x 80-bit FPU registers
       - MXCSR register
       - 16 x 128-bit XMM registers (lower 128 bits of YMM)
     - **SSE/XMM (if bit 1 set):** 256 bytes
       - 16 x 128-bit XMM registers (duplicate of X87 area, but separate in XSAVE)
     - **AVX/YMM (if bit 2 set):** 256 bytes
       - 16 x 128-bit YMM upper halves (upper 128 bits of each YMM register)

6. **XSAVE Size Calculation**
   - Header: 64 bytes
   - X87: 512 bytes (if XCR0 bit 0)
   - XMM: 256 bytes (if XCR0 bit 1)
   - YMM: 256 bytes (if XCR0 bit 2)
   - Total with all enabled: 1088 bytes (0x440)

### ✅ XRSTOR Instruction

7. **XRSTOR Implementation**
   - Restores extended state based on XCR0 and XSTATE_BV
   - Reads XSTATE_BV from header to determine what's saved
   - Only restores components that are:
     - Present in XSTATE_BV (saved)
     - Enabled in XCR0 (allowed)
   - Properly restores:
     - X87 FPU state
     - XMM registers (lower 128 bits)
     - YMM upper halves (upper 128 bits)

### ✅ CPUID Leaf 0x0D Updates

8. **CPUID Leaf 0x0D (Extended State Enumeration)**
   - EAX: Valid XCR0 bits = 0x07 (X87 + SSE + AVX)
   - EBX: Maximum XSAVE size = 0x440 (1088 bytes)
   - Correctly reports support for XMM + YMM state

## XCR0 Bit Meanings

- **Bit 0 (0x01):** X87 FPU state
  - FPU control/status/tag words
  - 8 x 80-bit FPU registers
  - MXCSR register
  - XMM registers (in FXSAVE format)

- **Bit 1 (0x02):** SSE/XMM registers
  - 16 x 128-bit XMM registers
  - Lower 128 bits of YMM registers

- **Bit 2 (0x04):** AVX/YMM registers
  - Upper 128 bits of 16 x 256-bit YMM registers
  - Extends XMM registers to 256 bits

## Memory Layout (XSAVE)

```
Offset    Size    Component
------    ----    ---------
0x000     64      XSAVE Header
                  0x000: XSTATE_BV (8 bytes)
                  0x008: XCOMP_BV (8 bytes)
                  0x010: Reserved (48 bytes)
0x040     512     X87 FPU State (if XCR0 bit 0)
                  0x040: FPU Control Word
                  0x042: FPU Status Word
                  0x044: FPU Tag Word
                  0x046: Reserved
                  0x048: FPU IP/DP
                  0x054: 8 x 80-bit FPU registers
                  0x0F4: MXCSR
                  0x0F8: MXCSR_MASK
                  0x0FC: 16 x 128-bit XMM registers
0x240     256     SSE/XMM State (if XCR0 bit 1)
                  16 x 128-bit XMM registers
0x340     256     AVX/YMM State (if XCR0 bit 2)
                  16 x 128-bit YMM upper halves
```
